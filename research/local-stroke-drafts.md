# Shared local stroke drafts

At baseline `ffb5bff`, the local editor shows a new stroke before committing it. Brush, linear and radial gestures draw the transformed soft coverage as a red raster in the mounted SVG overlay. Clone and Heal show the projected stroke path and source marker. The photo still uses its committed recipe. Trusted browser tests observe the live overlay and verify that cancellation clears it without saving. That revision's CLI can cancel the GUI stroke or save the normalized geometry, and `mask-preview` reads a saved mask. It cannot stage and inspect the same prospective geometry without writing the recipe. [Local tools contract](../docs/local-tools.md) · [Local gesture evidence](../tests/local-gesture.test.js)

## Existing transient owners

| Surface | Current behavior and scope |
| --- | --- |
| New brush, linear and radial geometry | The mounted photo maps pointer positions to normalized oriented-original coordinates with the existing inverse transform. Pointer motion updates an uncommitted coverage overlay. Pointer release adds one mask with neutral adjustments. |
| New Clone and Heal geometry | The same pointer owner constructs target points and retains the selected original-image source. The overlay draws the projected path and source marker. Pointer release adds one repair and applies the existing repair ordering. |
| Selected masks, repairs and composite components | The list and component selectors are session state. There are no drag handles that edit saved geometry. Their radius, feather, opacity and adjustment inputs display numeric text on `input` and run the existing update commands on `change`. |
| Range, depth and repair source controls | `range-color` already covers the new-range color draft and selected range refinement. The range fields, blur fields, source picker, overlay visibility and tool selection retain their current commands. Range/composite/semantic creation does not currently have a pre-save drawing gesture. |

## Command shape

Extend `mask.add` for brush, linear and radial geometry, and `repair.add` for Clone and Heal, with the same `draft: true` flag used by global adjustment commands. Geometry and validation are the existing typed contracts. Points are oriented-original fractions before crop, optics presentation, quarter-turn or reflection. Brush and repair radius is a fraction of the original short edge. Radial radii are separate fractions of original width and height. Clone and Heal carry an explicit source point, including one outside the current crop. A zero-length linear gesture remains local pointer bookkeeping until it has valid geometry. The existing minimum drag distance for committing a GUI linear stroke remains unchanged.

Full and summary `state` expose `localDraft` with the opaque ID, photo, typed command, normalized geometry and overlay visibility. `draft-commit` and `draft-cancel` use the same ID-based lifecycle as other adjustment drafts. `local-cancel` retains its current cancel-current behavior and photo guard. `preview --source local-draft --draftId ID` returns the published overlay as a transparent PNG at its displayed overlay dimensions. The existing `preview`, adjustment draft PNG and saved `mask-preview` retain their image contracts. A native workspace capture shows the layer composited with the photo and surrounding controls.

The published overlay is already an SVG containing an inline PNG for coverage or a vector path and circle for a repair. Serialize a snapshot of that same mounted layer and let the browser rasterize it for PNG readback. This preserves the current crop, rotation, reflection, optics transform, visibility and overlay opacity without calling the mask renderer again or introducing a repair preview renderer. Strip the viewport positioning from the snapshot and provide the SVG viewport's intrinsic dimensions. SVG image mode permits inline data resources and disallows external image loads. [SVG as an image](https://github.com/mdn/content/blob/main/files/en-us/web/svg/guides/svg_as_an_image/index.md) · [Canvas image drawing](https://github.com/mdn/content/blob/main/files/en-us/web/api/canvas_api/tutorial/using_images/index.md)

The mounted surface owns the draft. Selection, recipe changes, surface teardown, tool/source changes or a newer draft invalidate its prior ID. PNG readback checks the owner before and after asynchronous serialization. The local pointer still owns capture and coordinate collection. An already-queued cancel or replacement can invalidate that gesture even after physical pointer release, so the typed add checks the captured gesture again at execution. If release was queued first and saves successfully, a later cancel cannot undo it. An explicit commit uses the existing add, ID allocation, history and selection path once. Cancel adds no history and does not affect saved masks or repair order.

The design compares contracts. A dedicated nested local command envelope would duplicate the typed geometry parameters, and a new coverage renderer would need to reproduce the live layer's projection and visibility. Neither alternative was implemented.

## Runtime comparison

The focused Windows Chrome 156.0.8078.80 run passed 16 tests, including all five local stroke types. The actual decoded overlay contained stroke pixels and transparent exterior. The hidden mask overlay produced a fully transparent PNG. The saved recipe and photo preview stayed at baseline during staging and cancellation. A commit added one mask or repair and one undo restored the prior recipe and pixels. Original bytes matched. [Local draft workflow](../tests/local-stroke-drafts.test.js)

The baseline `ffb5bff` run held the command queue, enqueued `local-cancel`, then released a trusted pointer in each of the five tools before the queue resumed. Each cancel incorrectly reported `canceled:false` and the stroke saved. The updated focused race file passed both tests. Its cases compare decoded GUI and CLI overlay pixels under crop, turn and reflection, preserve replacements, and verify both queue orders. Cancel or replacement queued first blocks the released gesture. Release queued first saves once and a later cancel leaves that edit intact. A later asset or recipe rejects a stale gesture.
