# 交互范围

调查对象为 Windows Lightroom 9.4。入口依据为 [REA 账本](lightroom.md) 中的 R1/R3/L1/L2。菜单字节码的命令名、可访问性树里的控件、已执行端到端操作具有不同含义。下表记录已实现的功能路径及仍需对照的行为。

| 本机菜单或资源入口 | OpenLR 中的对应路径 | 尚未证明或未完成 |
| --- | --- | --- |
| 云图库、本地目录、添加照片 | 图库导入、磁盘原件引用、独立 WebDAV 库同步 | Adobe 账户同步、共享空间成员和权限、活动流与云搜索 |
| 网格、详情、胶片条、比较、放映 | Grid、Edit、Filmstrip、Compare、Slideshow；单键与原生菜单 | 所有平台逐个菜单位置和视觉等价性 |
| 选择、评级、旗标、相册、智能相册、堆栈、虚拟副本 | 多选、反选、按条件筛选、可编辑相册规则、时间/相似度堆栈、独立编辑参数 | 完整的智能规则集合、AI 选片评分、所有组织历史操作 |
| 光线、色彩、白平衡、曲线、对比原件、复制设置、版本 | 同一渲染路径供 GUI、CLI、输出使用；预设、分组选择复制和版本；三个固定滑块与自由点／RGB 通道曲线 | 明暗分区颜色分级和去雾尚未实现；Adobe 色调映射、色彩管理和完整过程版本兼容性未证明 |
| 蒙版与修复 | 线性/径向/画笔、人物/主体/背景/天空、克隆及纹理修复 | Adobe 服务端生成式修复、所有蒙版快捷键和模型等价性 |
| 导出与外部编辑 | 原图、带 XMP 的原图包、JPEG、PNG、TIFF、AVIF、JXL、DNG，选择元数据、输出色彩空间和独立输出锐化，多选逐张文件夹导出、实时进度／取消与完成清单，独立 TIFF 在外部编辑器保存后回库 | Photoshop 智能对象和多图层文档、所有元数据、纸张锐化校准和第三方程序互操作 |
| HDR、全景、视频 | 图像配准、线性 RAW 辐照度、全景合并；视频色彩、旋转、裁剪、时间范围、保留音轨导出 | 与原产品逐像素校准、每种输入编解码器和 HDR 显示器 |
| 迁移、发现、学习、Firefly 和连接拍摄 | 各专项进展以实际测试和文档为准 | Apple Photos/LrCat 全目录迁移、Adobe 社区和 Firefly 服务，实体相机兼容机型清单 |

`research/menu-bytecode.mjs` 可在原机按资源的字节范围重查特定命令。不把重复的隐藏快捷键项或调试命令计为独立产品功能。此表没有宣称与商业产品全面等价。

当前完整性检查和下一项核心实现的验证要求见[完成度审计](completion-audit.md)；点／通道曲线的原始证据及可复现插值消融见[点曲线研究](point-tone-curves.md)。研究方案不等于已交付功能。
