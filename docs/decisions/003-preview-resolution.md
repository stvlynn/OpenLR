# 按视口生成适屏预览

编辑滑块预览、导出、缩略图共用 `render`。适屏模式根据视口、长宽比和设备像素比例计算输出尺寸；100% 查看和默认导出保留源尺寸。这个决策只涉及编辑预览，RAW 解码仍保留全尺寸图像。

在 Windows、Chrome 155.0.8059.39 上运行 `node scripts/compare-preview.mjs`。输入是 3000 × 2000 的已知渐变，每个候选使用相同曝光、对比、阴影和饱和度参数。预热一次，记录三次像素处理并缩放到 960 × 640 的中位耗时。同尺寸逐通道平均绝对误差以全尺寸处理后缩小的结果为参考，通道值范围为 0–255。

| 处理长边 | 中位耗时 | 平均通道误差 |
| --- | ---: | ---: |
| 960 | 77 ms | 0.109 |
| 1280 | 126 ms | 0.308 |
| 3000 | 664 ms | 0 |

在该视口上，匹配显示像素比先处理全图快 8.6 倍。1280 像素的额外缩放对本次渐变没有收益。测试只覆盖一张合成图及全局调整。细粒度纹理、蒙版边缘、缩放倍率、硬件及平台会改变结果，因此保留原尺寸查看和导出路径。
